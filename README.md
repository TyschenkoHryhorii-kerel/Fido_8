Це база даних PostgreSQL для студентів і предметів. 
Є три таблиці: students, subject, helpingTable.
Для запуску закиньте у будь-який зручний редактор баз даних(при тестуванні використовувався supabase) та натисніть run.
Усередині вже є тестові дані з прикольними назвами(для розслаблення рекомендую прочитати табличку subject)
В кінці спрацьовує запит, який показує студентів 5-ї групи з програмування.
